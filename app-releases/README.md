# نشر تحديث أندرويد الداخلي

هذا المجلد هو مصدر موقع التحديثات المنفصل عن موقع الويب الرئيسي. يبقى ملف
`android.json` هو المصدر المعتمد لما يراه التطبيق عند الفتح. Firebase المجاني
يستضيف هذا الملف فقط؛ أمّا APK فيُنشر كمرفق **GitHub Release** لأن Firebase
Hosting يمنع الملفات التنفيذية في خطة Spark.

عند تجهيز إصدار جديد:

1. شغّل workflow باسم **Publish Android update** من GitHub Actions وأدخل
   الإصدار ورقم البناء وملاحظات الإصدار.
2. القيمة `mandatory` تبقى `false` ما لم يقرر مالك النظام جعل هذا الإصدار
   إلزاميًا. عند تفعيلها لا يستطيع المستخدم تجاوز شاشة التحديث.
3. ينشئ الـ workflow APK موقّعًا، يتحقق من SHA-256، ينشره في GitHub Releases،
   ثم ينشر ملف البيان إلى Firebase بالترتيب الآمن نفسه.

لا يُرفع ملف APK إلى Git، ولا تتأثر هذه الاستضافة عند نشر موقع الويب المعتاد.
